\section*{Code Availability}
\phantomsection
\addcontentsline{toc}{section}{Code Availability}
\label{section:code_availability}

All scripts and code used to compute the Technological Complexity Index and reproduce the results of this paper are publicly available in the following GitHub repository: \url{https://github.com/RintaroKARASHIMA/KCIinJapaneseFirms}.  
The implementation of the Economic Complexity algorithms is based on the \texttt{py-ecomplexity} library (MIT License), available at \url{https://github.com/cid-harvard/py-ecomplexity}.
